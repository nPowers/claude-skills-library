# Claude Skills Library

A curated, weekly-updated library of **Claude Desktop** and **Claude Code** skills, agents, sub-agents, and hooks — sourced from GitHub and Smithery, rewritten in proper format, and reviewed before publishing.

> **Part of the [AI Compare](https://github.com/nPowers/AICompare) project.**

---

## What's In Here

Every skill is a ready-to-use Markdown file following Anthropic's official skill format. Each file clearly states:

- What the skill does and when to use it
- Whether it works in **Claude Desktop**, **Claude Code**, or both
- Step-by-step instructions Claude follows when the skill is active
- Example trigger phrases
- Any important caveats or limitations

## Platform Compatibility

Every skill file includes a `## Platforms` section:

```markdown
## Platforms
- Claude Desktop: Supported
- Claude Code: Supported
```

**Claude Desktop** — Works in the standard Claude.ai chat interface. Uses conversational prompts and MCP server connections. No file system or terminal access required.

**Claude Code** — Works in the Claude Code terminal environment. Can read/write files, run Bash, execute Python, spawn sub-agents, and use lifecycle hooks.

## Weekly Update Schedule

New skills are added every **Monday** via the automated pipeline in `weekly-pipeline/`. Each week's batch is committed to a branch `week/YYYY-WNN` for review before merging to `main`.

The pipeline:
1. Searches GitHub and Smithery for new/updated Claude skills
2. Deduplicates against previously processed skills (SQLite tracking)
3. Rewrites descriptions into proper skill format using an LLM
4. Packages results with a summary spreadsheet
5. Commits to a review branch

## How to Use a Skill

### In Claude Desktop
1. Open Claude Desktop → Settings → Skills
2. Create a new skill and paste the contents of the `.md` file
3. The skill activates when you use a matching trigger phrase

### In Claude Code
1. Copy the `.md` file into your project's `.claude/skills/` directory
2. Or reference it in your `CLAUDE.md` file
3. Claude Code will follow the skill's instructions automatically
