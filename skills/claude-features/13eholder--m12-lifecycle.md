# M12 Lifecycle Mapper

## Description
Convert M12-style lifecycle semantics into standard lifecycle stages and actionable artifacts. Use this when you need to align M12-specific events with common operational workflows and monitoring.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported

## Instructions
1. Collect the M12 event definitions or a sample event stream from the user.
2. Map M12 event types to conventional lifecycle stages and explain the mapping rationale.
3. Generate a set of derived artifacts: stage descriptions, transition rules, and example alert conditions.
4. Offer sample summaries and a compact JSON mapping of M12 events to lifecycle stages for downstream tools.
5. Recommend best practices for instrumenting monitoring and handling edge cases.

## Example Usage
- "Map my M12 events to standard lifecycle stages"
- "Explain how M12 events should trigger alerts"
- "Produce a JSON mapping from M12 types to lifecycle phases"

## Note
Intended for analysis and planning; it does not integrate directly with monitoring systems or perform orchestration.
