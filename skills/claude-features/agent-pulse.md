# Agent Pulse Event Gateway

## Description
A local event gateway designed for AI code agents. It captures lifecycle events from Claude Code, Gemini CLI, and other sources, then fans them out to HTTP endpoints, webhooks, or connected devices for integration and monitoring.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (requires event capture and network communication capabilities)

## Instructions
1. Install Agent Pulse in your local environment.
2. Configure it to listen for lifecycle events from Claude Code and other AI agents.
3. Set up HTTP endpoints or webhooks to receive event data.
4. Use the gateway to route events to monitoring dashboards or automation systems.
5. Extend integrations to connected devices as needed.

## Example Usage
- "Start capturing agent lifecycle events"
- "Send events to webhook URL"
- "Monitor agent activity in real-time"

## Note
Agent Pulse requires Claude Code or compatible CLI tools to emit lifecycle events, so it is not available on Claude Desktop.
