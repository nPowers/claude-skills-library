# AI-company Multi-Agent Operating System

## Description
AI-company is a comprehensive multi-agent team operating system built for Claude Code. It features 108 MCP tools, over 40 agent templates, 10 lifecycle hooks, and 7 pipeline workflows. It supports persistent teams, structured meetings, task walls, and a real-time React dashboard. This system is a pure Claude Code native integration without dependencies on LangChain or AutoGen.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (requires code execution and multi-agent management)

## Instructions
1. Set up AI-company within your Claude Code environment.
2. Create and manage persistent multi-agent teams.
3. Use the provided MCP tools and agent templates to build workflows.
4. Organize structured meetings and maintain task walls.
5. Monitor team activity via the real-time React dashboard.
6. Customize lifecycle hooks and pipeline workflows as needed.

## Note
AI-company requires Claude Code due to its complex multi-agent orchestration and dashboard features. It is not supported on Claude Desktop.
