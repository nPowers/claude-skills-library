# AI-company Multi-Agent Operating System

## Description
AI-company is a native Claude Code multi-agent operating system featuring 108 MCP tools, over 40 agent templates, 10 lifecycle hooks, and 7 pipeline workflows. It supports persistent teams, structured meetings, task walls, and a real-time React dashboard. This system avoids external frameworks like LangChain or AutoGen, providing pure Claude Code integration.

## Platforms
- Claude Desktop: Not Supported (requires code execution and MCP integration)
- Claude Code: Supported (designed specifically for Claude Code multi-agent management)

## Instructions
1. Deploy AI-company to create and manage persistent multi-agent teams.
2. Utilize the extensive MCP toolset and agent templates to build workflows.
3. Use lifecycle hooks to customize agent and team behaviors.
4. Organize structured meetings and task walls for team coordination.
5. Monitor progress via the real-time React dashboard.

## Example Usage
- "Initialize AI-company multi-agent team"
- "Run pipeline workflows using AI-company"
- "Access AI-company's React dashboard for team status"

## Note
Requires Claude Code environment due to its reliance on MCP tools and real-time dashboard integration. Not compatible with Claude Desktop alone.
