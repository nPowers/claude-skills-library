# Managing Task Lifecycle

## Description
Guides Claude to create, plan, track, and close tasks using a clear task lifecycle. Use this skill when you need help defining states, acceptance criteria, estimates, priorities, owners, and monitoring plans for a single task or a collection of related tasks.

## Platforms
- Claude Desktop: Supported
- Claude Code: Supported

## Instructions
1. Ask clarifying questions about the task: objective, success criteria, stakeholders, constraints, and deadlines.
2. Propose a concise task title and a one-sentence description that captures the outcome.
3. Recommend a simple lifecycle model (example: Backlog → Ready → In Progress → Blocked → Review → Done) and list permitted transitions.
4. Define measurable acceptance criteria and exit conditions that must be met before moving a task to Done.
5. Break the work into subtasks, assigning an owner, an estimate (hours, days, or t-shirt size), and a confidence level for each subtask.
6. Identify dependencies and potential blockers, and suggest mitigation strategies for each.
7. Propose a priority and rationale (e.g., impact, urgency, compliance) and show how priority affects scheduling.
8. Specify required handoffs, approvals, or review steps and the responsible parties for each.
9. Provide a monitoring cadence (status update frequency), key progress metrics, and a template for quick status updates.
10. Supply escalation templates for common blocker scenarios (who to notify, what info to include).
11. Describe closure steps: verification, sign-off, documentation updates, and optional retrospective prompts.
12. Produce a compact, formatted summary of the entire plan and offer it as JSON or Markdown so the user can paste into a PM tool.
13. Ask whether to save this plan as a reusable template, apply it to other tasks, or modify estimates/priorities.

## Example Usage
- "Create and manage a task for launching the Q3 marketing campaign"
- "Help me define the lifecycle and acceptance criteria for this engineering ticket"
- "Turn these project notes into a tracked task with subtasks, estimates, and an update template"

## Note
I cannot access or modify external project management systems directly; outputs are templates and recommendations. Time estimates are heuristic—validate with your team and organization-specific processes.
