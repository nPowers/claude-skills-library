# Citadel Agent Orchestration Framework

## Description
Citadel is a robust agent orchestration framework designed for Claude Code. It supports four-tier routing, campaign persistence across sessions, parallel agents running in isolated worktrees, discovery relay between waves, lifecycle hooks, and circuit breaker functionality. It includes six production-quality skills and scales from solo developers to institutional use.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (requires code execution and multi-agent orchestration features)

## Instructions
1. Initialize Citadel within your Claude Code environment.
2. Configure routing tiers and campaign persistence as needed.
3. Deploy parallel agents in isolated worktrees for concurrent workflows.
4. Utilize discovery relay to coordinate agent waves.
5. Implement lifecycle hooks and circuit breakers to manage agent states.
6. Leverage built-in production skills or extend with custom agents.

- "Start a multi-agent campaign with Citadel"

## Note
Citadel requires Claude Code due to its reliance on code execution and advanced multi-agent orchestration capabilities. It is not available on Claude Desktop.
