# Claude Code Governance Framework

## Description
An automated governance system for Claude Code that includes a multi-model council, work-in-progress lifecycle hooks, company memory integration, and security gates. It helps enforce policies and manage agent workflows securely.

## Platforms
- Claude Desktop: Not Supported (requires lifecycle hooks and multi-model coordination)
- Claude Code: Supported

## Instructions
1. Deploy the governance framework within Claude Code.
2. Configure the multi-model council to oversee agent decisions.
3. Use WIP lifecycle hooks to monitor ongoing tasks.
4. Integrate company memory to maintain organizational context.
5. Set up security gates to enforce access and operational policies.

## Example Usage
- "Establish governance council for agent workflows"
- "Monitor work-in-progress tasks"
- "Apply security gates to sensitive operations"

## Note
This framework depends on Claude Code's lifecycle hooks and multi-agent capabilities and is not available on Claude Desktop.
