# Connection-Based Memory Lifecycle

## Description
Implements a memory lifecycle for Claude Code where memory entries linked to other knowledge persist, while isolated entries gradually fade. Entirely built using lifecycle hooks.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (relies on lifecycle hook execution)

## Instructions
1. Install the memory lifecycle hooks in Claude Code.
2. Track connections between memory entries to determine persistence.
3. Automatically fade isolated memory entries over time.
4. Use hooks to manage memory lifecycle events dynamically.

## Example Usage
- "Activate connection-based memory lifecycle."
- "Fade isolated memory entries automatically."
- "Maintain connected knowledge in memory."

## Note
Requires lifecycle hook support and code execution, so it is only available in Claude Code.
