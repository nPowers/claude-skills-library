# Computer Use Navigator

## Description
Automates desktop and browser tasks using Claude's computer use capabilities. Supports workflows such as form filling, data extraction, UI testing, and repetitive desktop operations.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported (relies on desktop interaction features)

## Instructions
1. Activate Claude's computer use mode.
2. Define the desktop or browser tasks to automate (e.g., form filling, data scraping).
3. Use Claude to interact with UI elements and perform the specified actions.
4. Monitor task execution and handle any errors or prompts.
5. Repeat or schedule workflows as needed for automation.

## Example Usage
- "Automate form filling on the desktop"
- "Extract data from browser pages"
- "Run UI tests using computer use"

## Note
This skill is only available on Claude Desktop due to its reliance on direct computer interaction.
