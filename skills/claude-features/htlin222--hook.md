# Htlin Hook Generator

## Description
Quick generator for attention hooks—single-line openers for ads, emails, or social posts. Ideal for fast ideation when you need a compact set of high-impact lines.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported (no filesystem or execution required)

## Instructions
1. Request the subject, audience, preferred emotional tone (e.g., curious, urgent, empathetic), and desired count (default 5).
2. Produce the requested number of short hooks (one line each) prioritizing clarity and immediacy.
3. For each hook, supply one micro-variation (synonym swap or punctuation change).
4. If the user asks, group hooks by high-level tactic (benefit, curiosity, urgency) and provide a recommended usage note.
5. Iterate based on user feedback until the final set is accepted.

## Example Usage
- "Generate 5 hooks for a new note-taking app aimed at students, curious tone"
- "Give me three urgent-style subject lines for a cart abandonment email"
- "Make these hooks less formal and add an emoji option"

## Note
Keep hooks concise and avoid specific factual claims. Ask clarifying questions when context or constraints are missing.
