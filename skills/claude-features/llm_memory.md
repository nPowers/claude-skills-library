# Persistent Memory System with MCP Server

## Description
A persistent memory solution for Claude Code featuring an MCP server backed by SQLite, session lifecycle hooks, and a web dashboard for memory management and monitoring.

## Platforms
- Claude Desktop: Not Supported (requires server and database access)
- Claude Code: Supported

## Instructions
1. Deploy the MCP server with SQLite database.
2. Enable lifecycle hooks in Claude Code to capture session data.
3. Access the web dashboard to view and manage persistent memory.
4. Use the system to maintain long-term context across sessions.

## Example Usage
- "Connect to MCP memory server"
- "Show persistent memory dashboard"
- "Retrieve stored session context"

## Note
This system depends on running a local server and database, restricting it to Claude Code environments.
