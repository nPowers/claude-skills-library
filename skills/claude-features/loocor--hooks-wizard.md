# Loocor Hooks Wizard

## Description
Interactive wizard that helps craft and refine short marketing hooks across channels. Best for users who want guided, iterative creation with presets and format-specific suggestions.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported (no filesystem or execution required)

## Instructions
1. Begin by asking these structured questions: goal (awareness, clicks, conversions), audience, channel, tone, and any constraints (length, banned words).
2. Present 3 preset strategies to choose from (Benefit-first, Curiosity-driven, Social-proof) and explain when to use each.
3. After the user selects a strategy, generate 5–7 hooks matching that strategy and the specified channel, labeling each by style.
4. Offer optional variations: shorten to a headline, adapt to another channel, or add emojis/hashtags when relevant.
5. Summarize recommended next steps (A/B test pairing, best posting times, brief metrics to track) and accept iteration requests.

## Example Usage
- "Run the hooks wizard for a freemium photo-editing app targeting college students: convert curiosity-driven hooks to Instagram captions"
- "I need short benefit-first hooks for a productivity newsletter — formal tone"
- "Give me 5 hooks and then make 3 of them shorter for SMS"

## Note
Clarify channel-specific constraints (e.g., character limits) before finalizing output. Avoid claims requiring verification.
