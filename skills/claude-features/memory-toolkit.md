# Memory Toolkit for Claude Code

## Description
Memory Toolkit is a session memory lifecycle plugin for Claude Code that provides structured markdown memory, workstreams, handoff capabilities, and auto-save hooks. It helps maintain organized, persistent memory across agent sessions.

## Platforms
- Claude Desktop: Not Supported (requires code execution and lifecycle hook integration)
- Claude Code: Supported (built for Claude Code session memory management)

## Instructions
1. Integrate Memory Toolkit into your Claude Code agent workflows.
2. Use structured markdown to organize session memory.
3. Employ workstreams and handoff features to manage task transitions.
4. Enable auto-save hooks to persist memory automatically.

## Example Usage
- "Activate Memory Toolkit for session persistence"
- "Use markdown memory to track agent context"
- "Configure auto-save for continuous memory updates"

## Note
This plugin is designed exclusively for Claude Code environments and is not compatible with Claude Desktop.
