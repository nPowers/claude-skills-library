# Swiz Cross-Agent Hook Manager

## Description
Manages and orchestrates lifecycle hooks across multiple AI coding assistants including Claude Code, Cursor, and Gemini. Installs hooks from a unified manifest to streamline cross-agent integration.

## Platforms
- Claude Desktop: Not Supported (requires orchestration and hook installation capabilities)
- Claude Code: Supported

## Instructions
1. Install Swiz in your Claude Code environment.
2. Prepare a manifest defining hooks for supported agents.
3. Use Swiz to install and manage hooks across agents.
4. Monitor and update hooks centrally through Swiz.

## Example Usage
- "Install hooks from manifest"
- "List active hooks across agents"
- "Update lifecycle hooks for Gemini"

## Note
Swiz requires code execution and multi-agent orchestration, so it functions only within Claude Code.
