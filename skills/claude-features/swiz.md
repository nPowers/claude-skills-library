# Swiz Cross-Agent Hook Manager

## Description
Swiz is a centralized hook manager that installs and coordinates lifecycle hooks across multiple AI coding assistants including Claude Code, Cursor, and Gemini. Use it to unify and streamline hook management from a single manifest.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (requires code execution and integration across agents)

## Instructions
1. Install Swiz in your Claude Code environment.
2. Define your lifecycle hooks in a Swiz manifest file.
3. Use Swiz to deploy and orchestrate hooks across supported AI coding assistants.
4. Monitor hook execution and manage updates centrally through Swiz.

## Example Usage
- "Activate Swiz to manage hooks across my AI coding assistants."
- "Deploy lifecycle hooks using Swiz manifest."
- "Coordinate hook execution with Swiz for Claude Code and Gemini."

## Note
Swiz requires code-level access and integration with multiple agents, so it is only supported in Claude Code environments.
