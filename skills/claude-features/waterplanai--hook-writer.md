# WaterplanAI Hook Writer

## Description
Generates short, attention-grabbing hooks (openers, taglines, subject lines, social media leads) tailored to product details, audience, tone, and platform. Use this when you need multiple hook variants and A/B test suggestions quickly.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported (no filesystem or execution required)

## Instructions
1. Prompt the user for: topic/product, target audience, channel (email, Twitter, Instagram, TikTok, etc.), preferred tone, and desired length or character limit.
2. If any required detail is missing, ask concise clarifying questions before generating hooks.
3. Produce 6–8 distinct hook variants, grouped and labeled by approach (e.g., curiosity, benefit, question, statistic, emotional, playful).
4. For each variant, include a one-line alternative phrasing and a recommended call-to-action (CTA) where applicable.
5. Provide 2 A/B test pairs with brief guidance on when to use each option (audience or context differences).
6. Offer a short customization checklist (words to include/avoid and length adjustments) and iterate when the user requests edits.

## Example Usage
- "Write 6 short social media hooks for a plant-based protein bar aimed at busy parents, playful tone"
- "Generate 4 email subject lines for a SaaS trial extension, formal tone, under 50 characters"
- "Create three TikTok opening hooks that start with a question about home workouts"

## Note
Do not invent verifiable facts or statistics. Ask follow-up questions whenever the user’s brief is ambiguous or missing key constraints.
