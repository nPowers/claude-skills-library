# Modern C# Coding Standards and Best Practices

## Description
Provides up-to-date coding standards, conventions, and modern idioms for C# development. Use this skill to create style guides, refactor code to modern APIs, and apply best practices for readability, maintainability, and performance.

## Platforms
- Claude Desktop: Supported
- Claude Code: Supported

## Instructions
1. Ask the user for their current style constraints: existing conventions, .editorconfig/StyleCop settings, and target .NET versions.
2. Request representative code samples or areas of the codebase to assess for modernization.
3. Produce a concise set of rules and examples covering naming, nullability, async patterns, immutability, records, pattern matching, exceptions, disposal, and performance-sensitive APIs.
4. Offer concrete refactor examples that transform legacy idioms into modern C# constructs with explanations of behavioral changes.
5. Recommend static analyzers, Roslyn-based code fixes, and editor configuration to enforce the standards automatically.
6. Provide a migration plan: incremental fixes, CI enforcement, and unit/integration regression checks to ensure behavioral parity.

## Example Usage
- "Create a modern C# style guide for our .NET 6 services"
- "Refactor this legacy class to use records and nullable reference types"
- "List recommended analyzers and rules for enforcing C# best practices"

## Note
I cannot run static analysis for you; provide code snippets and rule files for precise, testable recommendations.
