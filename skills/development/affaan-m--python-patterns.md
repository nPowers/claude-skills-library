5. If asked, refactor the provided code into the chosen pattern and show before/after examples.
6. Offer unit tests or usage examples and recommend modern Python features (dataclasses, typing, contextlib) where applicable.
7. Suggest alternative designs if concurrency, performance, or testing requirements change.
