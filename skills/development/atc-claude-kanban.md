# Claude Kanban Dashboard

## Description
A real-time Kanban board for monitoring Claude Code agent tasks, sessions, and subagents. Use this skill to visualize and track ongoing agent workflows through a browser interface.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (requires code execution and web server capabilities)

## Instructions
1. Activate the Kanban dashboard skill.
2. Connect to the Claude Code agent environment.
3. Access the browser-based Kanban board to view live task and session statuses.
4. Use the dashboard to manage and monitor subagents and their workflows.

## Example Usage
- "Show me the Claude agent Kanban board"
- "Open the real-time task dashboard"
- "Display current Claude Code sessions on Kanban"

## Note
This skill requires running a web server and access to Claude Code agent internals, so it is only supported in Claude Code environments.
