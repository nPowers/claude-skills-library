# Python Programming Helper

## Description
Provide clear explanations, examples, and solutions for common Python programming tasks and language features. Use this skill for learning, quick code snippets, algorithm help, or idiomatic Python advice.

## Platforms
- Claude Desktop: Supported
- Claude Code: Supported

## Instructions
1. Ask what the user wants to accomplish and the context (beginner, intermediate, production code, performance constraints).
2. Explain relevant Python concepts succinctly and show minimal, well-documented examples that can be copy-pasted.
3. For algorithms or data-structure tasks, provide complexity analysis (time/space) and an idiomatic implementation.
4. Offer alternative solutions when appropriate (built-ins, libraries, comprehensions vs loops) and explain trade-offs.
5. When asked for debugging help, request the smallest reproducible example and point out the precise issue with line references.
6. When appropriate, include type hints and short tests or assertions to validate correctness.
7. Conclude with recommended resources or further reading for continued learning.

## Example Usage
- "Explain list comprehensions with examples"
- "Show a Python function to merge two sorted lists with O(n) complexity"
- "Help me understand async/await in Python with a small example"

## Note
This skill provides guidance and code examples but cannot run or access files on Claude Desktop. Use Claude Code if you need live execution or environment-specific actions.
