# SQL Query Optimization Expert

## Description
This skill provides expert guidance on optimizing SQL queries, including analyzing execution plans, recommending index strategies, using window functions and CTEs effectively, and tuning queries for specific databases like PostgreSQL, MySQL, and SQL Server.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported (does not require code execution or file access)

## Instructions
1. Analyze the provided SQL query or execution plan.
2. Identify potential performance bottlenecks or inefficiencies.
3. Suggest improvements such as better indexing, query rewriting, or use of advanced SQL features.
4. Tailor recommendations to the specific database system mentioned (PostgreSQL, MySQL, or SQL Server).
5. Explain the rationale behind each optimization suggestion.

## Example Usage
- "Optimize this SQL query for better performance."
- "How can I improve the execution plan of this PostgreSQL query?"
- "Suggest index strategies for this MySQL database query."

## Note
This skill provides advisory support only and does not execute or test queries directly.
