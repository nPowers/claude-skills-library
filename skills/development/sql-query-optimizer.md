# SQL Query Optimization Expert

## Description
This skill provides expert guidance on optimizing SQL queries. It covers analyzing execution plans, choosing effective index strategies, utilizing window functions and common table expressions (CTEs), and applying database-specific tuning techniques for PostgreSQL, MySQL, and SQL Server.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported (does not require code execution or file system access)

## Instructions
1. Analyze the provided SQL query and database schema information.
2. Review the query execution plan to identify performance bottlenecks.
3. Suggest appropriate indexing strategies to improve query speed.
4. Recommend use of window functions or CTEs where beneficial.
5. Provide database-specific tuning tips tailored to PostgreSQL, MySQL, or SQL Server.
6. Summarize optimization steps and expected impact.

## Example Usage
- "Optimize this SQL query for better performance."
- "Explain how to improve indexing for this query in PostgreSQL."
- "Suggest ways to rewrite this SQL using window functions or CTEs."

## Note
This skill focuses on query optimization advice and does not execute or test queries directly.
