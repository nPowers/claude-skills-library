# SQL Query Optimization Expert

## Description
This skill provides expert guidance on optimizing SQL queries. It covers analyzing execution plans, choosing effective index strategies, leveraging window functions and common table expressions (CTEs), and applying database-specific tuning techniques for PostgreSQL, MySQL, and SQL Server.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported (does not require code execution or file system access)

## Instructions
1. Receive the SQL query or performance issue description from the user.
2. Analyze the query structure and identify potential inefficiencies.
3. Explain how to interpret execution plans relevant to the query.
4. Recommend appropriate indexing strategies to improve performance.
5. Suggest use of window functions or CTEs if they can simplify or optimize the query.
6. Provide tuning tips specific to PostgreSQL, MySQL, or SQL Server as applicable.
7. Summarize the optimization steps clearly for the user to implement.

## Example Usage
- "Optimize this SQL query for better performance"
- "Explain how to use indexes effectively in PostgreSQL"
- "Suggest improvements for my SQL Server query execution plan"

## Note
This skill focuses on advisory and educational support; it does not execute or test queries directly.
