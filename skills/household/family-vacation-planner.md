# Family Vacation Planner

## Description
Plan family-friendly vacations by generating itineraries, recommending accommodations, suggesting activities for all ages, creating packing lists, and providing budget breakdowns to ensure a smooth and enjoyable trip.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (requires code execution for itinerary generation and budget calculations)

## Instructions
1. Gather vacation preferences including destination, dates, family members’ ages, and budget.
2. Generate a detailed itinerary with activities suitable for all ages.
3. Recommend accommodations based on family needs and budget.
4. Create a comprehensive packing list tailored to the trip.
5. Provide a budget breakdown covering all major expenses.

## Example Usage
- "Plan a week-long family vacation to Disney World."
- "Suggest activities for kids and adults on our trip."
- "Create a packing checklist for a beach vacation."

## Note
This skill requires Claude Code due to its need for complex planning and data integration.
