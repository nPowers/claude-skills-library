# Family Vacation Planner

## Description
Assists in planning family-friendly vacations by creating itineraries, recommending accommodations, suggesting activities suitable for all ages, and providing packing lists and budget breakdowns.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (needs code for itinerary generation and budget calculations)

## Instructions
1. Gather destination preferences, travel dates, and family details.
2. Develop a detailed itinerary including activities for all age groups.
3. Recommend suitable accommodations.
4. Create packing lists tailored to the trip.
5. Provide a budget overview and cost estimates.

## Example Usage
- "Plan a week-long vacation for my family with young children."
- "Suggest activities for teenagers on our trip."
- "Generate a packing list for a beach vacation."

## Note
Requires code execution to generate personalized travel plans and budgets.
