# Family Vacation Planner

## Description
Plan family-friendly vacations by generating itineraries, recommending accommodations, suggesting activities suitable for all ages, and providing packing lists and budget breakdowns.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (requires code execution for itinerary and budget calculations)

## Instructions
1. Collect preferences including destination, travel dates, family size, and budget.
2. Create a detailed itinerary with activities for all age groups.
3. Recommend suitable accommodations.
4. Generate packing lists tailored to the destination and family needs.
5. Provide a budget breakdown covering all trip expenses.

## Example Usage
- "Help me plan a vacation for my family with young children."
- "Create a packing list for our beach trip next month."
- "Suggest activities and accommodations for a family-friendly holiday."

## Note
This skill requires Claude Code to manage complex planning and budgeting tasks.
