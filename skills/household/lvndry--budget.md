# Lvndry Household Budget Planner

## Description
A planner that helps households build practical monthly budgets and scenario plans. Use it to allocate income across bills, savings, and variable spending, and to create straightforward budgets for busy families.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported

## Instructions
1. Ask the user for monthly net income, number of household members, and recurring monthly obligations (rent/mortgage, utilities, loans, subscriptions).
2. Collect estimates for variable spending categories (groceries, transport, entertainment) and any financial goals (emergency fund, debt payoff, savings targets).
3. Propose a recommended allocation based on common frameworks (e.g., essentials, savings, discretionary) and adjust according to the user's priorities.
4. Present the budget as a simple month-by-month plan with suggested amounts per category and explain any trade-offs.
5. Offer variant scenarios (e.g., 10% more savings, aggressive debt payoff) and show the projected impact on target timelines.
6. Provide a concise summary the user can copy into a budgeting app or spreadsheet.

## Example Usage
- "Create a monthly budget with $5,000 net income for a family of four"
- "Help me allocate $800 per month to savings while keeping essentials covered"
- "Show a plan to pay off $7,000 of credit card debt in 12 months"

## Note
This planner requires you to supply income and expense figures; it does not access external accounts. Advice is illustrative and not professional financial counsel.
