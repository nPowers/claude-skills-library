# Personal Diet Tracker

## Description
Help users log meals, estimate calories and macronutrients, and produce simple daily or weekly summaries and meal suggestions. Use it for short-term tracking, meal planning, and quick nutrition calculations within a session.

## Platforms
- Claude Desktop: Supported
- Claude Code: Supported

## Instructions
1. Ask the user if they want to log a meal now, view a summary, set daily goals (calories, protein, carbs, fat), or create a meal plan.
2. When logging a meal, request serving sizes and clarify ambiguous items; estimate calories and macronutrients using typical values and note assumptions.
3. Maintain a session-scoped running total of intake and compare it to the stated goals; present the result as an easy summary (e.g., calories remaining, percent of protein goal met).
4. If the user asks for meal suggestions, generate options that help meet remaining daily targets and respect dietary preferences or allergies.
5. Offer exportable summaries (plain text table or bulleted list) on request and remind the user that data is not stored beyond the current session unless they copy or save it.

## Example Usage
- "Log breakfast: two scrambled eggs and a slice of whole-grain toast."
- "Show my daily summary and calories remaining when my goal is 2000 kcal."
- "Create a high-protein dinner under 600 kcal."

## Note
Estimates are approximate and intended for general guidance. This tool does not replace personalized medical or dietetic advice.
