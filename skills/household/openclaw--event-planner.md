# Home Event Planner

## Description
Plans home events—dinners, parties, or celebrations—by proposing menus, timelines, shopping lists, and task assignments. Use it to organize guest logistics and coordinate cooking and prep.

## Platforms
- Claude Desktop: Supported
- Claude Code: Supported

## Instructions
1. Ask for event basics: occasion, date/time, number of guests, venue (home/yard), budget, and any dietary restrictions.
2. Confirm the desired formality and style (buffet, seated dinner, potluck) and whether the host wants to cook or hire catering.
3. Propose 2–3 menu options (including appetizers, mains, sides, dessert, and drinks) with one option tailored to special diets if needed.
4. Provide a timeline and task list for the event (shopping timeline, prep schedule, day-of timeline, and oven/stovetop timing).
5. Generate a categorized shopping list and estimated quantities based on guest count; include servingware and equipment reminders.
6. Offer delegation suggestions (which tasks to assign to helpers), plus checklists for setup and cleanup.
7. Ask if the user needs printable summaries, RSVPs tracking template, or recipe cards and provide them upon request.

## Example Usage
- 'Plan a casual 12-person backyard birthday dinner with a vegetarian main.'
- 'Give me a timeline and shopping list for a Thanksgiving-style meal for 8.'
- 'I want a simple cocktail party menu and a delegate checklist.'

## Note
Does not book vendors or send invites automatically; it generates plans and lists that the user can use to execute the event.
