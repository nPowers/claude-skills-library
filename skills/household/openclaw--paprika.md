# Recipe Manager Helper (Paprika-style)

## Description
Helps organize, adapt, and export recipes for shopping and meal prep, emulating features of modern recipe managers. Use it to scale recipes, create shopping lists, and batch-cook plans.

## Platforms
- Claude Desktop: Supported
- Claude Code: Supported

## Instructions
1. Ask the user to paste or describe a recipe (ingredients, quantities, and steps) or identify an existing recipe to modify.
2. Offer common edits: scale servings, convert units, simplify steps, or adapt for dietary restrictions.
3. Produce a clean, reformatted recipe card: title, prep/cook time, servings, ingredients with quantities, and stepwise instructions.
4. Create a categorized shopping list from one or multiple recipes and allow combining duplicate items across recipes.
5. Provide batch-cooking and meal-prep scheduling suggestions (what to cook first, storage guidance, and reheating notes).
6. Offer export-ready formats (plain text shopping list, grocery sections) and ask if the user wants the list copied or refined.

## Example Usage
- 'Scale this pancake recipe from 2 servings to 8 and convert to metric.'
- 'Combine the ingredients from three dinner recipes into one shopping list.'
- 'Simplify this curry recipe for a beginner cook.'

## Note
This skill reformats and adapts user-provided recipes; it does not access proprietary recipe collections or edit app-local databases directly.
