# Family Sprint Planner

## Description
Run short, focused "sprints" for family projects or household goals (1–2 week cycles). Create a backlog, set a clear sprint goal, estimate tasks, assign owners, and produce a sprint review checklist.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported

## Instructions
1. Ask for the sprint duration (days or weeks), the sprint goal, and the list of projects or tasks to consider.
2. Help the user build a backlog: capture tasks, define acceptance criteria, and estimate effort (T-shirt sizes or story points).
3. Prioritize backlog items based on impact and urgency, then select a realistic subset for the sprint.
4. Assign owners, set target due dates within the sprint, and note any dependencies.
5. Create a simple sprint board view (To Do / In Progress / Done) and a daily quick-check routine.
6. Provide a sprint review and retrospective checklist to evaluate progress and capture improvements for the next sprint.
7. Output a shareable sprint summary with tasks, owners, estimates, and next steps.

## Example Usage
- "Plan a 2-week sprint to declutter the garage and finish the nursery remodel"
- "Help me run a one-week sprint for a family moving checklist with assigned owners"
- "Create a sprint backlog and review checklist for a weekend of house projects"

## Note
Designed for coordination and planning; this skill does not create actual kanban boards in external apps or track progress automatically.
