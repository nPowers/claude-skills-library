# Personalized Weekly Meal Planner

## Description
Create customized weekly meal plans based on dietary preferences, allergies, family size, and budget constraints. This skill also generates shopping lists, preparation schedules, and nutritional summaries to simplify meal management.

## Platforms
- Claude Desktop: Not Supported
- Claude Code: Supported (requires code execution for generating detailed plans and lists)

## Instructions
1. Collect dietary preferences, allergy information, family size, and budget.
2. Generate a meal plan covering all meals for the week.
3. Create a corresponding shopping list organized by store sections.
4. Provide a meal prep schedule to optimize cooking time.
5. Summarize nutritional information for the planned meals.

## Example Usage
- "Plan a weekly meal schedule for my family with gluten-free options."
- "Generate a shopping list based on this week’s meal plan."
- "Provide nutritional summaries for our meals this week."

## Note
This skill requires Claude Code due to its need for detailed data handling and list generation.
