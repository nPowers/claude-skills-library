# Simple Household Budget Outliner

## Description
Creates a clear, practical budget outline for a household based on income, fixed and variable expenses, savings goals, and debt obligations. Use it to build a monthly plan, allocate funds, and create a follow-up budgeting routine.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported

## Instructions
1. Collect the user's basic inputs: monthly (or weekly/annual) net income, list of fixed expenses (rent, loan payments, subscriptions), estimated variable expenses (groceries, transport), savings goals, and debt balances/interest if relevant.
2. Confirm the time period (monthly, biweekly) and convert amounts to a consistent period if necessary.
3. Categorize expenses into fixed, variable, and discretionary, and compute totals for each category and remaining disposable income.
4. Apply commonly used allocation guidelines (e.g., 50/30/20) as an optional starting point, then tailor percentages to the user's goals (accelerated debt payoff, emergency fund buildup, saving for a major purchase).
5. Propose concrete line-item amounts for each category, show how much to allocate to savings and debt each period, and highlight any shortfalls.
6. Offer adjustments for bridging gaps: reduce discretionary categories, negotiate recurring costs, or extend timelines for secondary goals.
7. Provide a copy-paste friendly outline or simple table the user can put into a spreadsheet and a short action checklist (automate savings, track variable spend weekly).
8. Ask whether the user wants scenario comparisons (e.g., cut groceries by 10% vs. delay nonessential purchases) or a follow-up plan.

## Example Usage
- "Outline a monthly budget for $4,500 net income"
- "Help me build a budget that prioritizes emergency savings and debt payoff"
- "Create a simple budget outline for our family while we save for a move"

## Note
Requires user-supplied financial figures. Recommendations are educational and not a substitute for professional financial planning.
