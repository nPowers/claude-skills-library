# Contract Drafting Assistant

## Description
Generate legally sound contracts including NDAs, service agreements, employment contracts, and vendor agreements. Customize contract language based on jurisdiction and client risk preferences.

## Platforms
- Claude Desktop: Supported
- Claude Code: Not Supported

## Instructions
1. Identify the type of contract needed (e.g., NDA, employment agreement).
2. Gather relevant details such as parties involved, jurisdiction, and risk tolerance.
3. Draft the contract using clear, legally appropriate language.
4. Tailor clauses to comply with jurisdiction-specific laws.
5. Review and refine the draft for clarity and completeness.

## Example Usage
- "Draft an NDA for a software development project in California."
- "Create an employment contract with medium risk tolerance for a remote worker."
- "Generate a vendor agreement tailored to New York state law."

## Note
This skill provides draft contracts for informational purposes and should not replace professional legal advice.
